# Decisões

Uma nota por decisão, nome no formato `AAAA-MM-DD titulo-curto.md`, a partir do
modelo [Decisão](../modelos/Decisão.md).

Decisão que já está explicada no [CLAUDE.md](../CLAUDE.md) não precisa ser
repetida aqui — este lugar é para as que surgirem daqui em diante e para as
longas demais para o CLAUDE.md.
